# BlogDex visual assets

`brand-source.jpg` is the user's original green BlogDex logo. `brand-logo.svg` embeds that same JPEG, trims the surrounding whitespace with its viewBox, and uses a display filter to make the white background transparent. It does not redraw the lettering. The welcome heading displays a white version of the same mark using CSS.

`auth-landscapes.png` is a background sprite generated with the built-in imagegen tool from the supplied login-screen style reference. CSS displays its left sunset half on the welcome card and its right night half on the login card. All headings and form controls are real HTML.

Generation prompt:

Use case: illustration-story. Asset: a single seamless landscape diptych background sprite for a real website, two equal-width portrait landscapes side by side, edge to edge, no gutter or frame. Reference image is STYLE AND SCENERY REFERENCE ONLY. Left half: dreamy peach-pink-orange sunset sky, softly glowing clouds, distant warm layered mountains, dark plum forest silhouettes in the bottom quarter, a few golden fireflies. Right half: deep indigo-blue starry night sky, bright full moon in the upper right quarter, soft blue clouds, layered blue-violet mountains and dark navy forest silhouettes in the bottom quarter. Keep the middle upper half of each landscape calm so live form fields and heading can overlay. Painterly digital illustration matching the reference scenery. Both halves have the same horizon height. Entire canvas rectangular, landscape overall with each half portrait. Absolutely NO text, letters, logos, buttons, input fields, interface elements, icons, watermarks, borders, rounded corners, white margins, or 'Made with AI'.
